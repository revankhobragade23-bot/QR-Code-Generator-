# 🔳 QR Code Generator

A simple Python project that generates a QR code from a URL or text.

I made this project while learning how Python libraries can be used to create useful and simple applications. The program takes the given data and converts it into a QR code image.

## 🚀 What It Does

- Generates a QR code from a URL or text
- Saves the QR code as a PNG image
- Uses the `qrcode` Python library
- Simple and beginner-friendly

## 🛠️ Technologies Used

- Python
- qrcode
- Pillow
